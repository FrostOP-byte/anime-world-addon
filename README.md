\# Anime World — Legal Sources



A Stremio 5 add-on starter using the official Stremio Addon SDK.



\## Requirements

\- Node.js 20 or newer

\- GitHub account

\- Render account



\## Local testing

1\. Open a terminal in this folder.

2\. Run `npm install`.

3\. Run `npm start`.

4\. Visit http://127.0.0.1:7000/manifest.json



\## Online deployment

1\. Upload the project to a GitHub repository.

2\. In Render, select New + > Blueprint.

3\. Connect the repository containing render.yaml.

4\. Deploy the service.

5\. Test the HTTPS /manifest.json endpoint.

6\. Install that manifest URL in Stremio.



\## Streams

No streams are enabled by default. Configure only HTTPS media

URLs that you own or are expressly authorized to distribute.

Hindi audio must be independently verified before marking it

as verified.



The initial episode metadata is a placeholder and must be

replaced with accurate metadata before public use.
